# 全体MT資料の教訓記載判定と処理中表示

## 指標の区別

- **全体MT資料共有件数**：対象ファイル数。既存APIキー `shared_lessons_total` は互換性のため維持するが、教訓の存在を意味しない。
- **教訓あり候補件数** `lesson_candidates_total`：自動抽出した本文に具体的な教訓らしい記述を検出し、人がまだ確認していない資料数。
- **教訓記載確認済み件数** `verified_lessons_total`：人が「教訓ありを確認」した資料だけを数える。自動候補は加算しない。1ファイルに複数の教訓があっても記載資料1件。
- **教訓要確認・未解析件数** `lesson_review_total`：読み取りできない、内容が曖昧、または未解析の資料数。

既存の年月日・参加者フィルタ、表、グラフ、根拠表示、CSVに同じ定義で追加した。未判定の参加者は従来どおり参加者フィルタの対象外（明示的に含める操作あり）。

## ローカル本文解析

実行用Pythonに `pypdf` を導入する。MAMPの非公開設定ファイルと同じディレクトリに `analysis-venv/bin/python` があれば自動使用する。別の実行環境はJSON設定の `analysis_python` に絶対パスで指定できる。

```sh
/private/analysis-venv/bin/python scripts/analyze_meeting_lessons.py --config=/private/sharepoint-meetings.json
```

PDF、PPTX、DOCXの本文をローカルで抽出する。画像・動画・旧Office形式・暗号化・破損・大きい資料・時間切れは「要確認」とし、「なし」扱いにしない。OCRは未実装。PDFはページ、PowerPointはスライド、Wordは本文の場所と根拠の短い引用を保存する。全文はキャッシュしない。外部AI・APIへ本文を送信しない。OneDriveのオンライン専用ファイルを開くとOneDrive自身がダウンロードする場合がある。

判定ルールは「教訓」「学んだこと」等の見出しと具体的な学びの文章の組み合わせ。空欄・なし・予定だけを除外し、曖昧な記述は要確認とする。意味の正しさを保証するAI判定ではなく、確認を減らすための保守的な候補抽出。自動「なし」も人が覆せる。文字抽出の順序やレイアウトによって誤判定しうるため、研究に用いる件数は確認済み指標を使う。

ファイルのサイズ・更新時刻・inode・判定ルール版を識別し、変更のない資料は本文を読み直さない。1ファイルにつき別プロセス、45秒で打ち切り、PDFは200ページ/ファイル60MB、OOXMLは対象XML展開20MBを上限にする。解析中も既存の完了済み結果を保持してファイルごとに保存する。

## 操作と確認

概要の「全体MT資料の本文を解析（変更分のみ）」で背景解析を起動する。進捗は完了数/全体数と処理中のファイル名を表示し、別タブも操作できる。画面は進捗のみを定期取得し、通常GETでは本文を解析しない。

「教訓の判定と確認」を開き、共通条件内の資料を10件ずつ確認する。自動判定・根拠文章・ページ/スライド・元資料のローカルパスを表示し、「教訓ありを確認」「教訓なしを確認」「確認を取り消す」を保存できる。PDF・画像は認証付き同一サーバーのプレビューで開ける。その他はFinderから元資料を確認する。

人の確認は非公開キャッシュの `analysis-reviews.json` に保存し、MySQLやOneDriveの元ファイルは変更しない。資料の解析識別子に紐づけ、資料が更新された場合は古い確認を新しい件数へ流用しない。画面を開いた時点と保存時点で解析結果が変わっていれば保存を拒否し、確認し直す。判定結果CSVには自動/人の確認、理由、根拠文章を含む。

定期同期CLIはOneDriveの正常な一覧更新後に背景解析を起動し、変更のない資料を再利用する。Macで有効な既存の定期実行から利用する。手動でいつでも変更分を解析できる。起動失敗や長時間進捗が更新されない場合は画面にその状態を表示する。

## 重い処理の表示と軽量化

概要・一覧・集計表等のAPI通信中は画面上部に処理名と経過秒数を表示する。完了前に前回値が残っていることを明記し、取得失敗時はエラーと再取得ボタンを表示する。新しい条件で同じ取得を開始した場合は古いリクエストを中止し、古い結果で上書きしない。取得中の対応するCSV出力を無効化する。

PHPの読み取りリクエストは認証後にセッションロックを解放して他の画面取得を待たせない。参加者照合は同一リクエスト内で再利用する。本文抽出は通常の表示経路と分離した背景プロセスで実行する。
