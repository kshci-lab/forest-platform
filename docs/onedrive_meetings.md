# OneDrive同期先からのMT集計

Graphアプリの承認が使えない環境では、大学アカウントのOneDriveでSharePointの2つの親フォルダをMacへ同期する。ダッシュボードはローカルのフォルダ名・ファイル名だけを読み、本文は開かず、元フォルダには書き込まない。

## Finderへ追加する

1. SharePointの `0010-研究MT` を開き、上部の **Add shortcut to OneDrive** を押す。選択肢があれば **My files** に追加する。日付フォルダではなく親フォルダを追加する。
2. Finderの大学用OneDriveで親フォルダと日付フォルダが表示されることを確認する。
3. `0011-全体MT` も同様。ただしすでにFinderに同期されている場合は追加し直さない。同じ対象を「Sync」とショートカット追加の両方で設定しない。
4. OneDriveの雲アイコンで「最新の状態」を確認する。ローカル読み取りだけではクラウドとの同期完了は判定できない。

[Microsoftの同期手順](https://support.microsoft.com/en-us/onedrive/sync/sharepoint-training/sync-sharepoint-files-and-folders)

## 設定

`onedrive_meetings.config.example.json` を非公開の場所へコピーし、実在する2つの親フォルダの絶対パスを記入する。Finderではフォルダを選択してOption+Command+Cでパスをコピーできる。名前が「研究室名 - 0011-全体MT」の場合もその実パスを使う。別年度のフォルダと取り違えない。

キャッシュディレクトリを0700で用意し、設定ファイルを0600で保存する。OneDrive同期フォルダや公開フォルダ内にキャッシュを置かない。

既存同様に `FOREST_SP_CONFIG` で設定ファイルを指定する。MAMPの場合、環境変数がなければ `/Applications/MAMP/forest-platform-private/sharepoint-meetings.json` を自動確認する（ソース位置から4階層上の非公開ディレクトリ）。環境変数の指定を優先し、設定ファイルが存在しなければ未設定のままになる。本番では明示的に環境変数を設定する。

```sh
/path/to/php scripts/sync_sharepoint_meetings.php --config=/private/path/sharepoint-meetings.json
```

一覧が新しい場合は「pending」とし、30秒以上後の再実行で一覧が同一の場合だけ正常キャッシュへ反映する。変更が続く間・片方のフォルダがない場合・読み取りできない場合は前回の正常キャッシュを保持する。待機時間はプログラム内で待たず、2回の実行を使う。画面の「OneDriveフォルダを再集計」からも同じ処理を行う。

定期実行には既存の `--due` を利用できる。cron等で5分ごとに呼び、ローカル方式は毎回一覧を確認し、pending/失敗は次回に再確認する（Graph方式は従来どおり1時間）。Macが起動していて、OneDriveが動作し、ログインしている必要がある。既存サーバーへMacのパスを設定しても読み取れない。本番サーバーへの結果転送はこの機能には含まれない。

## 集計・追跡上の違い

拡張子重複・実施日・対象外ファイル・参加者対応・集計表/グラフ/CSVは既存ルールを再利用する。ファイルの更新者は使わない。読み取りは親直下の日付フォルダとその直下の通常ファイルのみ。シンボリックリンクは追跡しない（設定された親フォルダ自体のFinderエイリアス/シンボリックリンクは実パスに解決する）。

OneDriveのローカル一覧はSharePointのファイルIDを公開しないため、`local-...` という**ローカル相対パス由来のID**を使う。同じ一覧で再実行しても重複しない。名前変更・移動は前回一覧を置き換えることで反映し、履歴を加算しない。ファイルIDの対応表はGraph方式と共通利用できないので、確認済みファイル名の完全一致対応表を使うか、ローカルIDで設定し直す。

根拠資料にFinderのローカルパスを表示し、CSVにも出す。URLが未設定ならSharePointリンクは推測しない。任意の `roots.*.web_url` に対象親フォルダの直接HTTPS URL（クエリ・共有トークンのないSharePointの実パス）を指定した場合のみ、その下のURLを生成する。共有リンクやAllItems.aspxの画面URLは直接フォルダURLではない。大学側のリンクの実際の動作は別途確認する。

ローカルの一覧が30秒間同一でもOneDriveがクラウドの最新状態に追いついている保証にはならない。画面上の日時は「最終ローカル読み取り」であって「SharePoint最終同期」ではない。初回・同期エラー後はOneDrive側の表示を確認する。



## 苗字による参加者照合（追加仕様）

利用者の指定により、ファイルID・拡張子を除く完全一致名の指定がない資料は、`participants.surname_aliases` の苗字表記で照合する。例：`"705669067": ["山内", "yamauchi"]`。空白なしの日本語フルネームから機械的に姓を切り出さず、登録ユーザーを確認して苗字表記を設定する。英字は大小文字を区別せず、全角英字も正規化する。英字の別の単語の一部分は一致させない（`kawa` と `nakagawa` は別）。数字・区切り記号・日本語説明が隣接する表記は対応する。

漢字はファイル名内の苗字を照合し、短い姓が長い姓の内部に含まれる場合は長い一致を優先する（江川を川に割り当てない）。同じ苗字に複数の登録者がいる場合や、資料名に複数人の苗字がある場合は未判定。既存の個別ファイル指定は苗字照合より優先し、無効なユーザーID・明示的なnull指定を苗字で上書きしない。ファイル名で発表者を対応させる運用上のルールであり、本文や更新者は使わない。反映にOneDriveの再同期は不要。


音声・動画の分類と録音の取り込みは [meeting_audio.md](meeting_audio.md) を参照。音声は資料共有数に加算せず、同期後にローカルで文字起こしする。
