# ファイルなしの全体MT教訓共有

利用者が共有を確認したが発表ファイルが存在しない事例は、資料ファイルと区別した補足共有記録として扱う。

- supplemental_lessons_total：ファイルなしの確認済み教訓共有記録。
- verified_lessons_total：確認済みの資料内教訓＋利用者確認済みの補足共有記録。
- shared_lessons_total：実際の資料ファイルだけ。補足と証拠画像は加算しない。
- general_mt_sessions：日付フォルダと補足記録から確認できた開催。同日の補足3人分は1開催で、同日の実フォルダが後から現れても二重加算しない。
- 参加者別の全体MT回数・確認済み教訓数に反映し、「ファイルなし教訓共有数」を独立した列で合計・平均・母分散に追加。

保存先は設定supplements_dir、未指定時はキャッシュの隣のmeeting-supplements/records.json。根拠画像は同フォルダのevidence/。派生キャッシュと分離した永続的な研究記録としてバックアップする。非公開領域の0700/0600で保存し、画像閲覧はダッシュボード認証を通す。

固定IDで重複排除し、OneDriveの再同期や本文再解析では削除・上書きしない。SRL教訓テーブルは変更せず、既存の教訓総数へ教訓本体を二重登録しない。

2026年7月13日は、利用者が鍵谷・島岡・山内の順に添付した3画像を根拠に各1件。共有日は利用者指定の7月13日。画像中のジャーナル活動期間は別メタデータに保存する。

新指標カードから集計タブへ進み、セルを押すと教訓本文・理由・活用機会・根拠画像を確認できる。根拠CSVには共有種別・補足ID・本文・画像URLを出し、ファイルIDは空欄。参加者フィルタは通常どおり。初期対象9名には鍵谷が含まれないため、鍵谷分を見るには参加者に追加するか選択解除する。

検証：scripts/test_meeting_supplements.php、scripts/test_sharepoint_dashboard.js。3人の共有を1開催・3教訓・0資料として扱い、参加者/期間フィルタ、安定IDでの重複防止、後から実フォルダが現れた場合、参加者別件数と根拠CSVを検証する。
