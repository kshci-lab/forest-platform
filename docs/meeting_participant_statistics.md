# 参加者別のMT件数・平均・分散

既存の参加者別表に研究MT資料件数、研究MT回数、全体MT回数、全体MT資料共有数、教訓記載確認済み数、教訓あり候補数、教訓要確認・未解析数を追加する。

資料の参加者は既存の苗字照合と個別指定による。同じ参加者・同じ日付フォルダの資料が複数あってもMT回数は1回。同じ日付の異なるフォルダは別回。資料件数の重複除外は既存ルール（研究MTは拡張子違いを統合、全体MTはファイルごと）。

表の合計は参加者別件数の和。開催回数の合計は延べ回数で、複数人が同じ回に資料を出した場合は全体のフォルダ数より大きくなりうる。未判定の資料は個人へ割り当てず、この表の合計・平均・分散にも含めない。未判定を表示する共通オプションを選んでもこの原則は同じ。

平均と母分散は選択参加者の0件も含む。未同期・読み取り不能の場合はMTの値と統計をnull（画面上「—」）にし、0件とは区別する。期間は実施日基準。既存の教訓等の指標はこれまでの日付基準を維持する。

検証：scripts/test_sharepoint_meetings.php に同回複数形式・複数人・0件・未判定・期間・MT平均/母分散のテストを追加。scripts/test_meeting_lesson_reviews.php で人の確認結果の個人件数への反映、scripts/test_sharepoint_dashboard.js で新しい列の描画を検証する。
