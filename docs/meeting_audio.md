# MT録音の取り込み・文字起こし・教訓との対応確認

## 運用

全体MTの実施日フォルダにボイスメモ等の音声を置く。`0011-全体MT/2026-07-27/全体MT.m4a` は2026年7月27日の全体MTへ紐付く。作成・更新日時ではなくフォルダの実施日を使い、研究MTと全体MTを混同しない。音声はMT全体に紐付き、初期段階では個人へ割り当てない。

音声形式：m4a/mp3/wav/aac/aif/aiff/caf/flac/ogg/opus。動画mp4/mov/m4v/mkv/avi/webmは別分類し、現段階では自動文字起こし対象外。資料はPDF/Office/画像/テキスト等の明示した拡張子。音声・動画・不明形式を資料共有数や教訓記載解析に含めない。従来資料扱いしていた動画も除外する。

OneDrive一覧には種類・サイズ・更新時刻を保持。30秒以上あけて2回同じ一覧を確認して同期する。Macの定期実行は5分間隔でローカル一覧を確認するため、同期安定確認から取り込みまで通常5〜10分程度。Macが起動・ログイン中で、OneDrive同期が完了している必要がある。手動再集計・音声処理も可能。Graph方式は引き続き通常1時間間隔。

## 保存と重複排除

音声は公開領域/OneDriveの外の `meeting-audio/` へコピーする（デフォルトは既存キャッシュの隣。audio_store_dirで明示指定可能）。資料・録音の原本を変更・移動しない。ディレクトリ0700・ファイル0600を基本とする。

- assets：音声のSHA256ハッシュ由来のファイル名。同一内容は再利用。
- catalog.json：開催ID・日付・MT種別・元ファイルID・アーカイブ音声・処理状態・共有時点の教訓/資料候補。
- transcripts：時刻付き発言・音声区間・対応候補。60秒分ごとに保存。
- contexts：当日の教訓・資料候補と署名。変更時に文字起こしを再利用して照合し直す。
- reviews / review-history：人の確認・取消の履歴。自動解析では上書きしない。

録音IDは開催IDと内容ハッシュから生成。同じ音声を同じ開催へ再投入・名前変更しても録音レコードを増やさない。別開催に同じ音声を置いた場合は別開催の記録として扱う。同日の複数ファイルは同じ開催の別録音として選択・再生し、時刻は各ファイル内の相対時刻。元ファイルが削除されてもアーカイブと文字起こしは保持し、元ファイルが一覧にないことを表示する。

## ローカル実行環境

Apple Silicon Macで検証。既存の非公開analysis-venvに `mlx-whisper` と `imageio-ffmpeg` を追加。公開Whisper smallのMLX変換モデルをダウンロードし、設定JSONと同じディレクトリのspeech-modelに保存する。任意のaudio_model_pathでローカルモデルのパスを設定できる。実行時にモデルをネットから探さず、ローカルconfig.jsonがなければエラーとする。音声・文字起こし・教訓本文を外部APIへ送信しない。

```sh
/private/analysis-venv/bin/python scripts/transcribe_meeting_audio.py --config=/private/sharepoint-meetings.json
```

モデル読込・変換・文字起こし・教訓との照合・完了/一部失敗を表示。文字起こしは変換済みPCMの実サンプル数で区切り、音声の何秒まで処理したかを表示する。最後の短い区間も整数サンプルで切り出す。中断時は保存した秒数から再開し、完了済み音声を再度認識しない。通常の画面GETでは音声を解析しない。録音ごとに失敗を記録し、他の完了結果を消さない。

定期同期CLIは音声ワーカーを起動する。変更のない原音はファイルID・サイズ・高精度更新時刻・inodeの署名でハッシュ計算を再利用する。本文解析は資料一覧が変化した場合または失敗復旧時だけ起動する。

公式実装：[MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper)、[利用モデル](https://huggingface.co/mlx-community/whisper-small-mlx)。モデルのダウンロードと、音声を外部サービスへ送る処理は別であり、後者は実装していない。

## 対応候補と人の確認

実施日とMT種別・日付フォルダで対象資料を絞り、当日の教訓記載解析の根拠文や補足共有記録を候補として保存。本文を取得できない資料は未取得と明示する。発言者と教訓の持ち主を分離し、話者は未判定のまま扱う。

文字起こしは最長約90秒・無音間隔により便宜的に区切る。意味的に1議論であると断定しない。文字の重なり・苗字への言及から最大3候補を出すが、スコアは確信度ではなく、自動で対応確定しない。対応なし・複数の教訓/資料・未確認を表現する。録音を選ぶと該当時刻からの再生、開始/終了秒の修正、複数候補の選択、対応なしの確認、取消を保存できる。

録音と解析/候補の版に確認結果を紐付ける。候補文脈が変わった際は古い確認を新しい候補に流用せず、確認履歴と旧文脈を保持する。音声再生エンドポイントはダッシュボード認証が必須で、IDを実ファイルパスとして使わず、byte Rangeに対応して途中再生できる。

L3の判定基準が未定義のため、本実装はL3を自動判定・確定しない。画面/CSVには判定基準未設定と表示する。録音なしを議論なしとして扱わない。

## 集計

MT録音ファイル数、録音のあるMT数、音声対応確認済み教訓・資料候補数を既存の表・グラフ・CSVへ追加。録音/開催数は共通期間のみ適用し、個人へ自動割当しない。音声との対応確認済み指標だけ参加者への対応が確認できた候補の持ち主を使う。同じ教訓候補が複数区間にあっても同一開催内では1件とし、L3の実績や教訓共有確認済み件数とは区別する。
